# 轻琴 (PianoEase) — 左手伴奏简化规则定义

> **日期**：2026-03-25
> **状态**：初稿，待乐理审核
> **关联**：02_product_positioning_and_roadmap.md → 核心能力 1：AI 曲谱降维

---

## 一、 设计原则

1. **右手旋律不动**：简化只针对左手伴奏部分，右手主旋律保持原谱不变。
2. **和声正确性优先**：无论哪个级别，简化后的和弦必须保持与原曲一致的和声功能（和弦根音、性质不变）。
3. **渐进式难度**：Lv1 → Lv2 → Lv3，每级之间是"只增加一点点"的跳跃，而非断崖式变难。
4. **听感自然**：简化后的伴奏配合右手旋律，整体听感不应"空洞"或"违和"。

---

## 二、 简化级别定义

### 总览

| 级别 | 名称 | 左手做什么 | 难度 | 适合谁 |
|---|---|---|---|---|
| **Lv1** | 根音长音 | 每个和弦只弹根音，长音保持 | ⭐ | 零基础，刚开始双手配合 |
| **Lv2** | 柱式和弦 | 根音 + 简单柱式和弦（同时按下） | ⭐⭐ | 能双手配合，想增加和声厚度 |
| **Lv3** | 简化分解和弦 | 根音 + 简单分解/半分解和弦音型 | ⭐⭐⭐ | 有一定基础，追求更完整的伴奏感 |
| **原谱** | 完整版 | 原谱左手部分，不做修改 | ⭐⭐⭐⭐+ | 进阶用户，挑战原曲 |

---

### Lv1：根音长音（最简化）

**核心规则**：
- 每个和弦仅弹**根音**（低八度），节奏简化为**每和弦长音保持**
- 4/4 拍：若一个和弦持续 2 拍，则根音按住 2 拍；若持续 4 拍，按住 4 拍
- 3/4 拍：根音按住整个小节（3 拍）或按和弦变化点切换

**音区规则**：
- 根音一般弹在**大字组或小字组**（钢琴中低音区），简谱记法加","表示低八度

**示例（以《友情岁月》前奏为例，1=bE, 4/4 拍）**：

```
第1小节：Am → F
右手：3'      1'6 631'6 ｜ 4       1'6 641'6
左手：6,,   (按住两拍)   ｜ 4,,   (按住两拍)

第2小节：E → Am
右手：3'      75 #5375  ｜ 3'      1'6 631'6
左手：3,,               ｜ 6,,
```

**Lv1 生成规则伪代码**：
```
对于每个和弦段落:
  1. 识别和弦名称 → 提取根音
  2. 将根音放到低八度音区
  3. 时值 = 该和弦在此小节中的持续拍数（长音保持）
  4. 力度 = mf (中等偏弱，不抢旋律)
```

---

### Lv2：柱式和弦（和弦进阶版）

**核心规则**：
- **第 1 拍**弹根音（低八度），**第 3 拍**弹柱式和弦（三和弦的 3 音 + 5 音同时按下，或根据和弦性质选择合适的转位）
- 本质上是**"低音 + 和弦体"**的拆分，类似华尔兹的"嗵-嚓"结构，但适配 4/4 拍

**4/4 拍常见节奏型**：
```
拍：  1       2       3       4
左手：根音    (保持)   [3音+5音]  (保持)
      ↓               ↓
    低音区           中音区
```

**3/4 拍常见节奏型**：
```
拍：  1       2       3
左手：根音    [3+5]   [3+5]
      嗵      嚓      嚓
```

**和弦配置规则**：

| 和弦类型 | 根音(1拍) | 柱式和弦(3拍) | 简谱示例(Am) |
|---|---|---|---|
| 大三和弦 (如 C) | 根音低八度 | [3音, 5音] | 1,, → [3, 5,] |
| 小三和弦 (如 Am) | 根音低八度 | [b3音, 5音] | 6,, → [1, 3,] |
| 属七和弦 (如 G7) | 根音低八度 | [3音, b7音] | 5,, → [7, 2] |
| 减三和弦 (如 Bdim) | 根音低八度 | [b3音, b5音] | 7,, → [2, 4] |
| 挂留和弦 (如 Csus4) | 根音低八度 | [4音, 5音] | 1,, → [4, 5,] |

**示例（《友情岁月》前奏 Lv2）**：

```
第1小节 (Am → F)
拍：  1        2            3        4
右手：3'    ｜ 1'6 631'6  ｜ 4     ｜ 1'6 641'6
左手：6,,   ｜ [1,  3,]   ｜ 4,,   ｜ [6,, 1,]

第2小节 (E → Am)
拍：  1        2            3        4
右手：3'    ｜ 75 #5375   ｜ 3'    ｜ 1'6 631'6
左手：3,,   ｜ [7,, #5,]  ｜ 6,,   ｜ [1,  3,]
```

**Lv2 生成规则伪代码**：
```
对于每个和弦段落:
  1. 识别和弦名称 → 提取根音、3音、5音、7音（如有）
  2. 第1拍：根音放到低八度音区
  3. 第3拍（4/4拍）或第2、3拍（3/4拍）：
     - 取和弦的 3音 和 5音 组成柱式和弦
     - 注意：优先选择靠近根音上方的最近转位，避免大跳
  4. 力度：根音 mf，柱式和弦 mp
```

### Lv3：简化分解和弦

**核心规则**：
- 左手弹**分解和弦音型**，但保持**简单重复规律**
- 每小节使用**统一的节奏型**（而非原谱中可能出现的复杂多变音型）
- 根据歌曲风格选择合适的分解音型

**常见分解和弦音型库**（4/4 拍）：

#### 音型 A：低-高-中-高（Alberti 变体）
```
拍：  1     2     3     4
左手：根    5音   3音   5音
     ↓     ↑     ↗    ↑
最经典的古典/抒情分解模式
```

#### 音型 B：低-中-高-中（上行下行）
```
拍：  1     2     3     4
左手：根    3音   5音   3音
适合抒情流行曲、慢歌
```

#### 音型 C：低-5-8-5（八度流动）
```
拍：  1     2     3     4
左手：根    5音   高8度根  5音
适合大气的流行/摇滚风格
```

#### 音型 D：半分解 — 低音+双音交替
```
拍：  1       2       3       4
左手：根     [3+5]    根     [3+5]
      单音    双音    单音    双音
适合节奏感强的歌曲，介于 Lv2 和全分解之间
```

#### 音型 E：八分音符连续分解
```
拍：  1  +  2  +  3  +  4  +
左手：根 5  3  5  根 5  3  5
16分音符流动，适合抒情独奏曲
```

#### 音型 F：3/4 拍华尔兹分解
```
拍：  1     2     3
左手：根    3音   5音
经典 "嗵-嚓-嚓" 的分解版
```

**Lv3 音型选择规则**：

| 歌曲特征 | 推荐音型 | 理由 |
|---|---|---|
| 慢速抒情 (BPM < 80) | B 或 E | 流动感强，温柔 |
| 中速流行 (BPM 80-120) | A 或 D | 经典且稳定 |
| 快速/节奏感强 (BPM > 120) | D 或 C | 简洁有力，不会手忙脚乱 |
| 3/4 拍 | F | 华尔兹固定模式 |
| 大气/激昂段落 | C | 八度流动，有空间感 |

**Lv3 生成规则伪代码**：
```
对于整首歌:
  1. 分析歌曲 BPM 和拍号 → 选择基础分解音型模板
  2. 对于每个和弦段落:
     a. 提取和弦组成音（根、3、5、7）
     b. 将组成音填入所选音型模板的对应位置
     c. 音区安排：根音在低八度，其余音在根音上方最近位置
  3. 段落间可微调：
     - 主歌(verse)用更安静的音型（如 B）
     - 副歌(chorus)切换到更有力的音型（如 A 或 D）
```

## 五、 简化过程中的特殊处理

### 5.1 和弦转换点的节奏对齐

简化后的左手和弦切换点**必须与原谱保持一致**。如果原谱在某小节的第 3 拍换和弦，简化版也必须在第 3 拍切换。

### 5.2 经过音与装饰音

- Lv1/Lv2：**完全去掉**经过音和装饰音
- Lv3：可保留简单的经过低音（如和弦根音之间的半音经过），但标记为"可选"

### 5.3 低音走向（Bass Line）

- Lv1：纯根音，不考虑低音线条
- Lv2：根音为主，但在和弦转换时可以使用**转位低音**让低音线更平滑（如 C → Am/E 而非直接跳到 Am）
- Lv3：鼓励使用平滑的低音走向

### 5.4 力度与踏板

- 所有级别：左手力度应轻于右手（建议 MIDI velocity 比右手低 10-20）
- Lv1/Lv2：标注弱延音踏板使用建议（每个和弦换踏板一次）
- Lv3：按原谱踏板标记或不额外标注

### 5.5 特殊拍号

| 拍号 | Lv1 处理 | Lv2 处理 | Lv3 处理 |
|---|---|---|---|
| 4/4 | 长音保持 | 1拍根音 + 3拍柱式 | 标准分解音型 |
| 3/4 | 长音保持 | 1拍根音 + 2,3拍柱式 | 华尔兹分解 |
| 6/8 | 长音保持 | 1拍根音 + 4拍柱式 | 复合拍分解 |
| 2/4 | 长音保持 | 1拍根音 + 2拍柱式 | 简单双拍分解 |

## 六、 算法输入与输出数据流

```
输入：MusicXML / MIDI 文件（完整双手谱）
  │
  ├─ Step 1: 解析右手旋律轨道 → 保持不变
  │
  ├─ Step 2: 解析左手伴奏轨道
  │    │
  │    ├── 和弦识别：逐小节识别和弦名称和持续时长
  │    ├── 和声分析：识别和弦进行模式
  │    └── 段落分析：识别 intro/verse/chorus/bridge
  │
  ├─ Step 3: 生成简化版
  │    │
  │    ├── Lv1: 和弦根音 → 长音保持
  │    ├── Lv2: 根音 + 柱式和弦（按和弦性质查表生成）
  │    └── Lv3: 根音 + 分解音型（按 BPM/风格选择模板填充）
  │
  └─ Step 4: 输出
       ├── 简化后的 MusicXML（作者源文件 / 可渲染五线谱）
       ├── 统一 chart JSON（运行时标准格式，供瀑布流/判定/报告共用）
       ├── 简谱数据（可渲染简谱视图）
       └── MIDI 数据（可在音游模式中回放或调试）
```

## 七、 待讨论 & 下一步

1. **Lv3 音型是固定整首歌还是分段落切换？** 建议副歌段比主歌段更有力
2. **是否需要 Lv2.5？** 即"半分解和弦"（音型 D），作为 Lv2 到 Lv3 的过渡
3. **七和弦/九和弦在 Lv2 中怎么处理？** 是否简化为三和弦？建议 Lv2 保留七音
4. **和弦转位在 Lv2 中的使用程度？** 平滑低音线 vs 始终根音位
5. **用户能否自定义选择分解音型？** 未来功能考虑
