## 二、 竞品分析

### 2.1 海外主流竞品

| 产品 | 定位 | 核心特色 | 定价 (年) | MIDI 支持 | 曲谱简化 | AI 纠错深度 |
|---|---|---|---|---|---|---|
| **Simply Piano** | 零基础入门 | 结构化课程 + 游戏化 + 实时反馈 | ~$150 | ✅ | ❌ 无分级简化 | 浅（音准/节奏） |
| **Flowkey** | 以曲带练 | 视频教学 + 等待模式 + 丰富曲库 | ~$130 | ✅ | 有多难度编排 | 浅 |
| **Yousician** | 游戏化多乐器 | 强游戏化 + 多乐器 + 挑战模式 | $120-180 | ✅ | ❌ | 浅（音准/节奏） |
| **Synthesia** | 瀑布流可视化 | MIDI 下落式 + 等待模式 + 指法标注 + 双手颜色区分 | 买断 ~$39 | ✅ (核心) | ❌ 原谱展示 | 无主动分析 |
| **MuseFlow** | AI 视奏训练 | AI 自适应难度 + 视奏专项 | 订阅制 | ✅ | ✅ AI 自适应 | 中（识别演奏模式） |
| **Piano Marvel** | 练习追踪 | 评估模式 + 练习日志 + 弱点识别 | 订阅制 | ✅ | ❌ | 中 |
| **ROLI AI Coach** | AI 手型指导 | 红外手部追踪 + 手型/姿势纠正 + 对话式指导 | 硬件捆绑 | ✅ | ❌ | **深**（手型+演奏） |

### 2.2 国内主流竞品

| 产品 | 定位 | 核心特色 | 商业模式 | 优势 | 短板 |
|---|---|---|---|---|---|
| **小叶子钢琴** | AI 陪练（偏儿童） | AI 琴音识别精准度高 + 郎朗代言 + 游戏化激励 + "学+练"一体 | 付费课程/订阅 | 品牌力强、用户量领先、全球131国 | 偏低龄、无曲谱简化、专业考级精度存疑 |
| **弹琴吧** | 曲谱社区 + 多乐器 | 海量曲谱（千万用户）+ AI 乐谱生成 + 跟弹练习 + 五线谱⇄简谱切换 | Freemium + SVIP | 曲谱资源丰富、社区活跃、AI 从音视频生成乐谱 | 陪练深度不足、非纯钢琴垂直 |
| **郎朗AI练琴** | 考级陪练 | 考级曲目精准识别 | 订阅制 | 考级场景强 | 场景单一 |

### 2.3 竞品能力矩阵 — 轻琴的机会窗口

```
                    曲谱简化能力
                       ↑ 高
                       │
            轻琴(目标) │  MuseFlow
                       │
              ─────────┼──────────→ AI纠错深度
                       │            高
          Flowkey      │  ROLI AI Coach
        Simply Piano   │
          Synthesia    │
                       │
                     低 │
```

**关键洞察**：
1. **"AI 曲谱分级简化"是一片蓝海**。现有竞品要么提供原谱（Synthesia），要么让编辑团队人工编排多难度版本（Flowkey），没有产品做到"AI 自动将任意五线谱按难度级别降维，尤其是左手和弦的智能简化"。
2. **AI 纠错普遍停留在"对不对"层面**，缺乏"为什么错"和"怎么改"的深度诊断。
3. **国内产品偏儿童考级**，成人自学市场空间大。
4. **五线谱 ⇄ 简谱切换**弹琴吧在做，但无分级简化配套。

## 三、 目标用户画像

### 3.1 核心用户群 A：20 多岁年轻成人

| 属性 | 描述 |
|---|---|
| **年龄** | 20-28 岁 |
| **场景** | 刚工作不久、有自己的空间，买了电钢琴想培养一个爱好 |
| **学琴史** | 零基础或小时候短暂接触过 |
| **痛点** | 五线谱看不懂（尤其左手）、自学没有反馈、容易放弃 |
| **心理** | 想快速弹出一首完整的流行歌发朋友圈/社交 |
| **特点** | 对 App 和游戏化接受度极高，愿意尝试新工具 |

### 3.2 核心用户群 B：40 岁以上回炉重练者

| 属性 | 描述 |
|---|---|
| **年龄** | 40+ 岁 |
| **场景** | 孩子大了 / 退休前后，有闲暇时间重拾年轻时的音乐梦 |
| **学琴史** | 可能小时候学过几年、有一定乐理基础但生疏了 |
| **痛点** | 手指机能退化、复杂五线谱力不从心、传统老师不好找 |
| **心理** | 不追求考级，享受弹琴过程本身的愉悦感 |
| **特点** | 付费意愿较强，更看重"有用"而非"花哨" |

> **30 岁左右的中坚群体**反而不是核心用户 -- 工作家庭压力大，没有精力投入练琴。

### 3.3 次要用户（远期）：琴童家长

| 属性 | 描述 |
|---|---|
| **场景** | 孩子在学琴，家长无法辅导日常练习 |
| **痛点** | 不知道孩子弹得对不对，练琴吵架 |
| **备注** | V1.0 暂不作为核心用户，但 AI 纠错能力天然适配此场景 |
